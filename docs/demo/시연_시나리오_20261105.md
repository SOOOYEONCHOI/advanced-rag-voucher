## 2. 단계별 진행 대본

### 1단계. 문서 등록 (3분)

**화면:** 문서 관리

1. 파일 선택 영역에 엑셀·PDF 2개를 함께 끌어다 놓는다(여러 파일 동시 등록).
2. 입력 항목을 보여준다.
   - 대화 주제: 엑셀 → `NEOCON 제조 표준`, PDF → `산업안전 법규`
   - 문서 유형 / 파서 선택 / 청크 크기(비우면 자동)
   - 파일별 **모델명** 칸: 엑셀은 `NEOCON C2` 입력(파일명이 기본값으로 들어오고 수정 가능)
3. 업로드 → **처리 현황**에서 파일별 단계 표시(대기 → 처리 중 → 완료), 전체 완료 수 진행 막대를 보여준다.
4. 멘트: "자동 확인을 꺼도 서버 처리는 계속되고, 실패하면 이 자리에서 재처리 버튼으로 다시 돌립니다."

> 진행 팁: 미리 등록을 끝낸 상태라면 "처리 현황"은 작은 파일 하나로 보여주고, 실제 대상 2개는 아래 목록에 이미 완료 상태로 있는 것을 보여준다.

### 2단계. 파싱·전처리·임베딩 설명 (3분, 구두)

**화면:** 엑셀 원본(`제습 Rotor Module 조립` 시트) → 필요하면 `제조공정도` 시트

설명 포인트:

| 구분 | 엑셀 (작업표준 SOP) | PDF (법령) |
|---|---|---|
| 구조 추출 | 시트 18개를 각각 문서 단위로 분리. 한 행 = 한 작업 단계(번호·작업 내용·Check Point·필요 Tool/Bolt·작업 인원·작업 공수) | 편·장·절·조 구조, 조문 단위로 나눔 |
| 메타데이터 | 모델명(NEOCON C2), 시트명, SOP 제목·버전(예: `SOP_ROTOR 조립 ver.0.1`), 작성 일자, 총 작업 공수 | 법령명, 공포 번호·시행일(제00450호, 2026-03-02), 조문 번호, 페이지 |
| 이미지 | 셀에 붙은 사진을 추출해 **해당 작업 단계에 자동 연결**(장식 이미지 제외). 이 파일은 사진 약 130장 | 텍스트 중심 |
| 저장 | 텍스트는 임베딩 후 벡터 DB, 사진·원본은 별도 저장소. 답변 시 단계와 함께 사진을 꺼내 보여줌 | 출처 페이지로 원문 PDF 이동 가능 |

멘트 예: "Rotor 조립 시트를 보시면 행마다 사진·작업 내용·체크 포인트가 있는데, 이걸 단순 텍스트로 뭉개지 않고 '단계 6 = 이 사진 + 이 내용'으로 묶어 저장합니다. 그래서 답변에 해당 단계 사진이 같이 나옵니다."

### 3단계. 문서 관리·버전 관리 (2분, 개발 중 기능)

**화면:** 문서 관리 → 등록 문서 목록

1. 목록에서 모델명·파일명·상태를 보여준다. 모델명은 클릭해서 바로 수정 가능.
2. 파일명 클릭 → **원본 열기**.
3. 엑셀 행의 **최신본 변경** 버튼 → 새 파일을 올리면 새 버전이 처리되는 동안 기존 버전으로 계속 답변하고, 완료되면 최신본이 바뀐다는 점을 설명.
4. **버전 이력** 버튼 → 미리 올려 둔 v1/v2 이력을 보여준다.
5. 멘트: "현장에 개정본이 배포되면 최신본 변경만 하면 됩니다. 챗봇은 항상 최신본 기준으로 답하고, 예전 버전은 이력으로 남습니다. 이 부분은 현재 개발 중입니다."

### 4단계. 챗봇 시연 (7분)

**화면:** 챗봇. 대화 주제를 바꿔 가며 질문한다.

#### [메인 질문 A] 엑셀 — 사진이 함께 나오는 질문

**대화 주제:** `NEOCON 제조 표준`

> **"C2 제습 로터 벨트 텐션 세팅은 어떻게 해?"**

예상 답변 요소 (출처: `제습 Rotor Module 조립` 시트, Belt Tension Setting 절):
- 기준값 **90Hz ± 5Hz**, 측정기 Belt Tension Meter(10~600Hz)
- 벨트가 케이스 지지대 볼트 안쪽에 있는지 확인, Rotor 쪽 Belt Gear 리벳과 벨트 간섭 없게 위치
- Tensioner Bolt로 조정: **시계 방향 = 텐션 증가(주파수↑), 반시계 = 감소**
- 주파수는 **각 벨트 중앙에서 측정**, 측정값을 정면 Bolt Cap에 기입
- 구동 테스트로 회전 확인(**C2 Rotor는 시계 방향 회전**), Slip 발생 시 11mm 스페너로 조금씩 조정 후 재확인
- 작업 시간 30분(1대 기준)
- **해당 단계 사진**이 답변 아래 갤러리로 표시 → 사진 클릭해 크게 보기

멘트: "현장 작업자가 SOP 책자를 뒤지지 않고, 이 장비 이 단계의 기준값과 사진을 바로 받습니다."

#### [메인 질문 B] PDF — 법령 수치 질문

**대화 주제:** `산업안전 법규`

> **"밀폐공간 작업할 때 적정공기 기준이 뭐야?"**

예상 답변 요소 (출처: 제618조 정의):
- 산소 **18% 이상 23.5% 미만**
- 이산화탄소 **1.5% 미만**, 일산화탄소 **30ppm 미만**, 황화수소 **10ppm 미만**
- 산소결핍 = 산소농도 18% 미만
- (함께 나올 수 있음) 제619조 밀폐공간 작업 프로그램: 작업 전 산소·유해가스 농도 측정 결과 확인 등

#### [음성 질문] 마이크로 질문 → 미리듣기 → 전송

짧고 발음이 쉬운 문장으로 고른다. 둘 중 하나.

| 주제 | 음성 질문 | 예상 답변 요소 (출처) |
|---|---|---|
| 엑셀 | **"팬 모듈 방진고무 체결 토크 얼마야?"** | 방진고무 체결력 **118kgf·cm**, FAN-브래킷 **34kgf·cm**, 록타이트 사용 권장, 체결 후 I-Marking(`FAN Module 조립`, `Module Check Sheet` 시트) |
| PDF | **"사다리식 통로 기울기는 몇 도 이하야?"** | **75도 이하**, 고정식은 90도 이하, 높이 7m 이상이면 바닥에서 2.5m 지점부터 등받이울, 길이 10m 이상이면 5m 이내마다 계단참, 폭 30cm 이상(제24조) |

진행: 마이크 버튼 → "마이크 연결 중" → 녹음 → 정지 → **미리듣기로 녹음 확인** → 인식된 문장이 입력창에 들어가면 전송.

> 음성 인식이 틀리면 당황하지 말고 입력창에서 고쳐 전송한다. "인식 결과를 보내기 전에 확인·수정할 수 있게 설계했다"는 점이 오히려 시연 포인트.

### 5단계. 참조 문서 확인 (3분)

**화면:** 답변 하단 출처 → 출처 패널

1. **질문 A(엑셀) 답변의 출처** 클릭
   - 출처 패널에 파일명·시트명·근거 내용 표시
   - **"원본 시트에서 보기"** → 원본 시트 화면에서 해당 위치 확인
   - Excel 다운로드로 원본 파일까지 확인 가능
   - 연결 이미지 "원본 보기"로 사진 확대
2. **질문 B(PDF) 답변의 출처** 클릭
   - 근거 조문 내용 표시 → **원본 PDF를 새 탭으로 열어 해당 페이지** 확인(제618조, 약 111쪽)
3. 멘트: "AI가 지어낸 답이 아니라, 어느 문서 몇 쪽·어느 시트에서 왔는지 바로 따라가서 검증할 수 있습니다."

### 6단계. 관리자 기능 (2분)

**화면:** 사용자 권한 → 대화 주제 설정

1. **사용자 권한** 화면: 사용자 / 소속 부서 / 실질 접근 대화 주제(부서 권한 − 개인 차단) / 상태 열을 보여준다.
2. 부서 탭: 부서별 기본 접근 주제 설정.
3. 특정 사용자 **권한 설정** 팝업 → `NEOCON 제조 표준` 차단.
4. **권한 효과 시연:** 타 부서 계정으로 로그인 → 챗봇 주제 목록에 `NEOCON 제조 표준`이 없음, 해당 문서 내용·사진·출처가 어디에도 나오지 않음을 보여준다.
5. (선택) 대화 주제 설정 화면, 통계 화면을 잠깐 보여준다.
6. 멘트: "부서 단위로 기본 권한을 주고, 개인별로 막을 수 있습니다. 권한 없는 문서는 검색·답변·출처·사진 어디에도 나오지 않습니다."

## 3. 리허설 체크리스트

| 확인 | 항목 |
|---|---|
| ☐ | 두 문서 처리 완료, 문서 목록에 모델명 `NEOCON C2` 표시 |

| ☐ | 질문 B 답변에 18% / 23.5% / 1.5% / 30ppm / 10ppm이 정확히 나온다 |

| ☐ | 엑셀 출처 "원본 시트에서 보기", PDF 출처 원본 페이지 열기 동작 |

| ☐ | 타 부서 계정에서 차단 주제가 안 보인다 |
