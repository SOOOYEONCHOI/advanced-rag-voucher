말씀하신 GPU 서버(H100 80GB × 8장) 사용 현황을 운영 배포 기준으로 정리해 회신드립니다.

---

## 1. 현재 사용 현황

현재 저희는 8장 중 **2장(0번·1번)**만 사용하고 있습니다. 모든 서비스는 설정으로 0·1번 GPU에만 고정해 두었습니다.

| GPU | 용도 | 모델 | 메모리 사용 |
|---|---|---|---|
| 0번 | 답변 생성(LLM) | Qwen3.5-9B | 약 55.8GB |
| 0번 | 문서 파싱 | docling-parser | 약 2.6GB (대기 시) |
| | **0번 합계** | | **약 58.4GB / 80GB** |
| 1번 | 임베딩(검색용 벡터 변환) | Qwen3-Embedding-4B | 약 14.9GB |
| 1번 | 리랭커(검색 결과 재정렬) | bge-reranker-v2-m3 | 약 2.3GB |
| 1번 | 음성 인식(STT) | Qwen3-ASR-1.7B | 약 7.2GB |
| | **1번 합계** | | **약 24.4GB / 80GB** |
| 2~7번 | 사용 안 함 | – | – |

※ GPU 사용률이 0%로 보이는 것은 측정 시각(오전 8시)에 요청이 없었기 때문입니다. 모델 서빙 프로그램(vLLM)은 시작할 때 정해진 만큼 메모리를 먼저 확보해 두기 때문에, 위 메모리 수치는 요청이 없어도 유지됩니다. 실제 연산은 질문이 들어올 때만 일어납니다.

## 2. 앞으로 추가할 모델과 필요 메모리

1차 년도 범위에 따라 아래 두 모델을 추가로 올려야 합니다.

| 추가 항목 | 용도 | 후보 모델 | 필요 메모리(추정) |
|---|---|---|---|
| TTS | 답변을 음성으로 읽어주기 | Qwen3-TTS-1.7B | 약 20GB |
| VLM | 흐름도·도면 등 이미지 인식 | Qwen3-VL-8B | 약 25~35GB |
| | **합계** | | **약 45~55GB** |

VLM은 도면·흐름도처럼 해상도가 높은 이미지를 다뤄야 합니다. 그래서 모델 자체 크기(약 17GB)에 더해 이미지를 처리할 메모리 공간이 넉넉히 필요합니다.

## 3. 배치 방안

**(1) 현재 2장 안에서 운영하는 경우**
- 1번 GPU에 있는 모델들의 메모리 설정을 줄이면 TTS와 VLM까지 1번 GPU에 함께 올릴 수 있습니다.
- 다만 여유 메모리가 거의 남지 않습니다. 사용자가 몰리거나 모델을 바꿔야 할 때 대응할 여지가 부족합니다.

**(2) 추가 할당을 받는 경우 (요청드리는 방안)**
- VLM을 별도 GPU에 두면 서비스 모델끼리 메모리를 다투지 않습니다. 도면 인식 품질이 부족할 때 더 큰 모델로 바꿔볼 수도 있습니다.

## 4. 추가 GPU 할당 요청

현재 서비스에는 운영 환경에 실제로 적용할 수 있는 **저사양(소형 파라미터) 모델만** 올려 두었습니다. LLM 9B, 임베딩 4B, 음성 인식 1.7B, VLM 8B(예정) 수준입니다. 서비스 응답 속도와 GPU 자원을 고려한 선택입니다.

다만 이 모델들이 품질 면에서 충분한지 판단하려면, 더 큰 모델과 같은 질문으로 비교해 볼 필요가 있습니다. 예를 들면 30B급 이상 LLM, 32B급 VLM 같은 고사양 모델입니다. 고사양 모델은 1장으로는 올리기 어렵거나 2장 이상을 묶어야 하는 경우가 많습니다. 지금의 2장으로는 운영 서비스를 유지하면서 이런 비교 테스트를 진행하기가 어렵습니다.

그래서 가능하시다면, 현재 사용하지 않는 2~7번 GPU 중 일부를 저희 쪽에 추가로 할당해 주시면 좋겠습니다.

- **상시 1장**: VLM(흐름도·도면 인식) 전용
- **테스트용 1~2장**: 고사양 모델 비교 테스트(LLM 최종 선정 평가 포함). 상시 점유가 어렵다면 테스트 기간에만 한시로 사용하는 방식도 괜찮습니다.

테스트 결과는 모델별 정답률·응답 시간 비교표로 정리해 공유드리겠습니다. 테스트가 끝나 필요 없어진 GPU는 바로 반납하겠습니다.

## 5. 요약

- 현재: H100 2장 사용 (0번 LLM·문서 파싱 약 58GB, 1번 임베딩·리랭커·STT 약 24GB)
- 추가 예정: TTS 약 20GB, VLM 약 25~35GB (합계 약 45~55GB)
- 요청: VLM용 상시 1장 + 고사양 모델 테스트용 1~2장 (총 3~4장)
