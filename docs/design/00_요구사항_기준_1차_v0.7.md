## 4. 업무 시나리오 (SC-01~13, 테스트 기준)

1차 통합 테스트 대상은 **SC-01~SC-10**(SC-04는 👍/👎까지). SC-11~13은 2차. 관련 화면 ID는 정의서 표기 그대로이며, 화면 목록은 `02_화면_API_ID_목록.md`를 따른다.

#### SC-01 텍스트로 작업 방법 질문 — 작업자 · 1차
- 사전 조건: 로그인, 질문 대상 문서가 최신본으로 등록됨
- 기본 흐름:
  - ① 챗봇 화면에서 대화 주제 선택 후 질문 입력(예: "FAN Module 조립 순서 알려줘")
  - ② "문서 검색 중" → "답변 생성 중" 상태 표시
  - ③ 작업 단계형 답변(단계별 사진 썸네일·인용 번호) + [관련 이미지](번호·제목·시트!셀) + [참고 문서] 표시
  - ④ 같은 대화에서 이어서 질문(대화 이력 저장·표시, 앞 질문으로 검색어를 보완하는 멀티턴은 2차)
- 예외 흐름:
  - 근거 없음 → "문서에서 찾지 못했습니다" + 비슷한 문서 안내
  - 권한 없는 문서 → 검색 결과에서 제외
  - 생성 중 오류 → 다시 시도 버튼
- 결과: 근거 기반 답변·출처 확인, 대화 이력 저장
- 관련 요구사항: R4-1, R4-2, R4-4, R4-5, R6-1 · 관련 화면: UI-02, UI-03, UI-05

#### SC-02 음성으로 질문 — 작업자 · 1차
- 사전 조건: HTTPS 접속, 마이크 권한 허용
- 기본 흐름:
  - ① 마이크 버튼 → "말씀해 주세요" 표시, 녹음(경과 시간·음량)
  - ② [녹음 완료] → "음성을 텍스트로 변환 중…"
  - ③ 음성 인식 결과 패널에서 문장 확인, 틀린 부분 직접 수정(용어 사전 인식 단어 표시)
  - ④ [바로 질문] → 이후 SC-01 ②~③과 같음, 질문에 "음성 질문"(수정 시 "인식 결과 수정됨") 표시 / [질문에 적용] → 입력창에서 더 고친 뒤 전송
- 예외 흐름:
  - 마이크 권한 거부 → 허용 방법 안내
  - 소리 없음·너무 짧음 → 다시 녹음 안내
  - 인식이 틀림 → 수정 또는 [다시 녹음]
  - 인식 실패 → 텍스트 입력으로 전환
- 결과: 음성 질문 답변, 인식 결과 이력 저장(오디오 미저장)
- 관련 요구사항: R5-1 · 관련 화면: UI-07, UI-02, UI-03

#### SC-03 사진·출처 원본 확인 — 작업자 · 1차
- 사전 조건: 사진이 포함된 답변 받음
- 기본 흐름:
