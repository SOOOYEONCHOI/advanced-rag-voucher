    공통

    • URL은 /api 기준, 인증은 기존 Authorization: Bearer. 401은 기존 로그인 만료 처리.
    • 서버 설정 DRAWING_PARSE_MODE: 기본 off. backend일 때만 /ingest/options의 drawing_ingest_extensions가 ["dwg","dxf"]로 내려온다. 화면은 이 배열만 보고 도면 기능을 켠다(설정 이름을 화면에 하드코딩하지 않음).
    • 권한: 처리 결과 보기는 문서를 볼 수 있는 사용자 모두(볼 수 없으면 404). 검수는 업로드한 본인 또는 관리자, 그리고 현재 버전만 — 버튼은 역할명이 아니라 응답의 can_review로 정한다.
    • 도면은 이번 단계에서 임베딩·검색 DB에 넣지 않는다(search_status="not_indexed", chunk_count=0). 챗봇 화면 변경 없음.
    • 기존 API 필드는 그대로이고 drawing 계열 필드만 추가된다. 도면이 아니면 drawing=null. 모르는 필드는 무시한다.
    • 시간은 KST 문자열(YYYY-MM-DD HH:mm:ss) — 다시 변환하지 않는다. 오른쪽 위 연동판 패널·노란 주석은 확인용이며 제품에 구현하지 않는다.

    연동 체크리스트
      

    • DRAWING_PARSE_MODE=off: 확장자 안내·.dwg 선택·유형 칩·[처리 결과]가 모두 없고 기존 화면과 같다(회귀).
      • 

    • 도면 2개 + 엑셀 1개를 함께 올리면 도면 행은 5칸, 엑셀 행은 4칸. 도면만 고르면 문서 유형 "도면(자동)" 고정·파서 비활성.
      • 

    • 완료 행 요약·같은 품번 안내·"완료 · 확인 필요" 칩, 실패 행의 error_code 문구와 [재시도].
      • 

    • 목록 3줄째 품번·Rev, 상태 칩, "1매 · A3", 유형 칩 토글이 대화 주제 칩과 함께 걸림.
      • 

    • 처리 결과 6개 탭이 응답 필드대로 그려지고, 이미지는 인증 이미지로 로드·확대. 빈 표·빈 이미지 문구 확인.
      • 

    • 다른 사용자 도면은 보기만(can_review=false, 버튼 비활성·툴팁). 검수 완료 → 토스트 → 목록 "검수 완료", 취소도 같은 흐름.
