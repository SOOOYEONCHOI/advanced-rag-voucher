## 1. 2단계 시작 조건 (설계 1장 "2단계 전환 기준")

1. 정답 표 대비 표제란 필수 3필드 100%, BOM 행 누락 0
2. 샘플과 다른 양식 도면 2~3장 추가 검증(미결 Q-4)
3. 검색 적용 대상 도면의 관리자 검수 완료
4. LibreDWG·ODA 라이선스 검토 완료(Q-1), D-25·D-26 승인

## 3. 1단계가 2단계에 넘겨주는 것 (인터페이스 계약)

1단계 보고서에서 아래가 충족됐는지 먼저 확인한다. 하나라도 빠졌으면 2단계 시작 전에 보완한다.

| 항목 | 1단계 산출 | 2단계 사용처 |
|---|---|---|
| 청크 본문·접두 | `tb_chunks.chunk_text`, `heading_path` | 임베딩 입력 |
| 포인트 ID | `tb_chunks.point_id`(계산만, 미색인) | Qdrant upsert |
| `meta_json` 키 | `doc_type`, `part_no`, `drawing_no`, `rev`, `rev_major`, `rev_iter`, `drawing_kind`, `sheet_size`, `scale`, `content_type`, `section_label`, `item_no`, `citation_label`, `image_roles`, `chunker_version`, `ir_schema`, `confidential` | payload, 출처 카드 |
| 토큰 수 | `token_count`(상한 이하 보장) | 임베딩 한도 |
| 청크↔이미지 | `tb_chunk_resources` | [관련 이미지] |
| 재생성 | `rechunk`(IR만으로) | 검색 결과를 보고 청크 문구·크기 조정 시 |
| 검수 상태 | `tb_document_events`(review) | [검색 적용] 허용 조건 |
| 검색 플래그 | `tb_documents.search_enabled`(도면 false, 기존 문서 true) | 검색 필터 |
