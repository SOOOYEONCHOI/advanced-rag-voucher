# 시연 시나리오 — 지능형 작업표준 안내 AI (2026-10-30 코드 기준)

> 목적: 등록 → 질문 → 답변(사진) → 출처 확인까지 1차 핵심 흐름을 15분 안에 보여 준다.
> 기준: 현재 `adrag_frontend`(AdminView·ChatView·CitationPanel·ImageViewer·SpreadsheetViewer)와 변경로그 D-01·D-14·D-16·D-20.
> 관련 시나리오: SC-01(텍스트 질문), SC-02(사진 포함 답변), SC-06(개정본 교체), 음성 질문(UI-07).

## 0. 사전 준비

| 항목 | 확인 내용 |
|---|---|
| 서버 | 백엔드·PostgreSQL·Qdrant 기동, `GET /api/health` 가 `healthy` |
| 설정 | `EXCEL_PARSE_MODE=backend`, `EXCEL_IMAGE_LINK_ALL=true` |
| 계정 | 관리자 계정 1개(문서 등록용), 대화 주제 권한이 있는 작업자 계정 1개(선택) |
| 대화 주제 | 시연용 대화 주제 1개를 [대화 주제 설정]에서 미리 만들어 둔다 |
| 시연 파일 | 사진이 들어 있는 조립 절차서 엑셀 1개 + 같은 문서의 개정 파일 1개(내용이 다른 파일 — 같은 파일이면 409) |
| 미리 등록 | 처리에 시간이 걸리므로 **시연용 엑셀은 미리 1회 등록**해 두고, 시연에서는 다른 파일로 등록 과정만 보여 준다 |
| 질문 준비 | 답이 확실히 나오는 질문 3개를 미리 확인해 둔다(작업 순서, 특정 단계, 체결 토크 등) |
| 음성 | 마이크가 있는 PC, 브라우저 마이크 권한 허용, 음성 인식 서버 연결 확인 |

## 1. 문서 등록 (관리자 · 문서 관리 UI-12) — 약 4분

| 순서 | 동작 | 보여 줄 것 · 설명 멘트 |
|---|---|---|
| 1-1 | 관리자로 로그인 → 사이드바 **문서 관리** | "작업표준 문서는 관리자가 이 화면에서 올립니다." |
| 1-2 | **문서 업로드** 카드에 엑셀 파일을 끌어다 놓기 | 최대 10개 동시 선택 가능 |
| 1-3 | **대화 주제** 선택 | 대화 주제 = 문서 묶음 단위. 작업자는 권한 있는 주제만 볼 수 있음 |
| 1-4 | 파서 선택이 비활성되고 안내 문구 확인 | "엑셀은 전용 처리기로 처리됩니다" — 시트 구조·작업 단계·사진 위치를 그대로 읽는 전용 처리기 |
| 1-5 | 처리 현황의 **모델명** 확인(파일명이 자동으로 채워짐, 수정 가능) → **업로드 시작** | 모델명은 문서 목록·버전 이력에서 쓰는 이름, 최신본을 바꿔도 유지 |
| 1-6 | 진행 단계 표시 확인: **파일 준비 → 파싱·청킹 → 임베딩 → 저장** | 처리 중 새로고침해도 서버 처리는 계속됨. 완료 시 "검색 데이터 저장 완료", 처리 결과(페이지·청크 수) |
| 1-7 | 아래 **업로드된 문서** 목록에서 미리 등록한 문서 행 확인 | 모델명 · 파일명 · 현재 버전 · 최근 변경일 |

## 2. 개정본 교체 (SC-06) — 약 2분

| 순서 | 동작 | 보여 줄 것 · 설명 멘트 |
|---|---|---|
| 2-1 | 문서 행의 **[최신본 변경]** → 개정 파일 선택 → **업로드 및 최신본 변경** | 시스템이 추측하지 않고 관리자가 "이 문서의 다음 버전"으로 지정 |
| 2-2 | 행에 "처리 중" 표시 확인 | 처리가 끝날 때까지는 **현재 버전으로 계속 답변**, 실패하면 현재 버전 유지 |
| 2-3 | 완료 후 **[버전 이력]** 열기 | v1(교체)·v2(적용) 이력, 등록·적용·교체 시각. "현재 적용 중인 버전만 검색에 사용됩니다." |

> 개정 처리에 시간이 걸리면 2-1만 보여 주고, 2-3은 시연 끝에 다시 확인한다.

## 3. 챗봇 질문·답변 (작업자 · UI-02·03) — 약 4분

| 순서 | 동작 | 보여 줄 것 · 설명 멘트 |
|---|---|---|
| 3-1 | 작업자(또는 관리자)로 챗봇 화면 → 왼쪽에서 **대화 주제** 선택 | 권한 있는 주제만 목록에 보임 |
| 3-2 | 준비한 질문 1 입력(예: "○○ 조립 순서 알려줘") | 진행 표시 "문서 검색 중..." → "답변 생성 중...", 답변이 실시간으로 표시됨 |
| 3-3 | 답변 본문 확인 | 단계별 설명 + 인용 번호 **[1]** + 단계 옆 **사진 번호 배지** |
| 3-4 | 답변 아래 **관련 이미지** 카드 | 엑셀의 사진이 해당 작업 단계에 자동으로 연결되어 함께 나옴(D-20) |
| 3-5 | **[참고 문서]** 목록 | 답변 근거가 된 파일명 |
| 3-6 | 👍 클릭 | 답변 평가 저장(1차는 좋아요/싫어요 저장까지) |
| 3-7 | 질문 2·3 연속 질문 → **새 대화** 로 초기화 시연(선택) | 1차는 질문마다 독립 검색, 대화 이력은 저장·표시 |

## 4. 출처 보기 (UI-04·05) — 약 3분

| 순서 | 동작 | 보여 줄 것 · 설명 멘트 |
|---|---|---|
| 4-1 | 답변의 **[1]** 또는 참고 문서 항목 클릭 → 오른쪽 **참고 문서** 패널 | 상단에 현재 질문과 "답변으로 이동" |
| 4-2 | 출처 카드 확인 | 파일명 · **시트명 / 셀 범위**, 근거 내용 미리보기(근거 문장 강조) |
| 4-3 | 카드의 **연결된 이미지 N장** 확인 | 이 근거 범위에 연결된 사진 |
| 4-4 | 사진 또는 관련 이미지 카드 클릭 → **이미지 뷰어** | 제목, `n / N`, ←/→ 이동, 출처(시트!셀), 주변 설명, [사진 원본 열기] |
| 4-5 | 출처 카드의 **원본 시트에서 보기** | 원본 엑셀을 화면에서 바로 열고 **답변 근거 범위**가 강조됨, 시트 탭 이동·확대/축소 |
| 4-6 | **Excel 다운로드**(선택) | 원본 파일 다운로드 |

> 멘트: "답변이 어느 문서의 어느 시트, 어느 셀에서 나왔는지 바로 확인할 수 있어, 작업자가 원문을 다시 찾지 않아도 됩니다."

## 5. 음성 질문 (UI-07) — 약 2분

| 순서 | 동작 | 보여 줄 것 · 설명 멘트 |
|---|---|---|
| 5-1 | 입력창 옆 **마이크** 버튼 | "말씀해 주세요" 표시(마이크 입력이 없으면 경고) |
| 5-2 | 질문을 말한 뒤 **녹음 완료** | 녹음 다시 듣기 가능 |
| 5-3 | **텍스트 변환** | 인식 결과가 편집 가능한 상태로 표시. "인식 결과 · 내용을 확인하고 수정해 주세요." |
| 5-4 | 필요하면 글자 수정 → **질문하기**(또는 Ctrl+Enter) | 질문 말풍선에 "음성 질문", 수정했으면 "· 인식 결과 수정됨" |
| 5-5 | 이후 답변·출처는 3·4절과 동일 | 장갑을 낀 현장에서도 말로 질문 가능 |

## 6. 마무리 정리 멘트 (1분)

1. 엑셀 작업표준을 올리면 **작업 단계·사진·위치까지 자동으로 구조화**되어 검색에 쓰입니다.
2. 작업자는 **텍스트나 음성**으로 묻고, **사진이 붙은 단계별 답변**을 받습니다.
3. 모든 답변은 **문서·시트·셀 범위까지 출처**를 보여 주고 원본 시트에서 근거 위치를 확인할 수 있습니다.
4. 개정본은 관리자가 지정하며, **처리가 끝나야 최신본으로 바뀌므로** 처리 중에도 답변이 끊기지 않습니다.

## 7. 시연에서 보여 주지 않는 것 (현재 미구현·2차)

| 항목 | 상태 |
|---|---|
| 음성 답변 듣기(TTS, UI-08) | 1차 범위이나 **화면 미연결** — 시연에서 제외하거나 "개발 중"으로 안내 |
| DXF 도면 등록 | 1차 시범 모듈(`DRAWING_PARSE_MODE` 기본 off) — 시연 제외 |
| 용어·동의어 사전 화면(UI-19), AI 모델 관리(UI-21) | 화면 없음 |
| 문서 단위 사용자 권한(D-04) | 현재 화면은 **부서·대화 주제 단위 권한**(사용자 권한 관리) |
| 이전 버전 복원([이 버전 적용]), 사진 연결 검수(UI-15), 멀티턴, 👎 사유 입력 | 2차 |

## 8. 문제 발생 시 대처

| 상황 | 대처 |
|---|---|
| 등록이 오래 걸림 | "처리는 서버에서 계속됩니다" 안내 후 미리 등록한 문서로 진행 |
| 같은 파일로 최신본 변경 시 오류 | 같은 파일은 중복으로 거부됨(409) — 내용이 다른 개정 파일 사용 |
| 답변에 사진이 안 나옴 | 10-22 이전에 등록한 문서는 사진 자동 연결이 반영되지 않음 → 삭제 후 재등록한 문서 사용 |
| 음성 인식 실패 | [다시 녹음] 또는 텍스트 질문으로 전환 |
| "찾지 못했습니다" 응답 | 대화 주제 선택·권한 확인, 미리 검증한 질문으로 다시 질문 |
