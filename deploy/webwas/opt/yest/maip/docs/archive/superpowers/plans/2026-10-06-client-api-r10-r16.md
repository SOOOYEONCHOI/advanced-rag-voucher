- 라우트를 더하면 `urls.py` 의 `api/v1/<path:rest>` catch-all **앞**에 넣는다. 뒤에 두면 범용 `api/<task>/<view>` 가 받아 401 HTML 이 나간다.
- **비밀은 소스·커밋·로그·오류 메시지에 넣지 않는다.** API Key·비밀번호·토큰 전부다.
- **오류 메시지에 내부 진단 정보를 넣지 않는다.** 파이썬 예외 원문·파일 경로·스택이 Client 로 나가면 안 된다.
- RLS 를 우회하거나 제거하지 않는다.
- 모든 Git Commit 메시지는 **한국어**로 작성한다. Conventional Commits 의 type 만 영문.
- `main` 에 직접 커밋하지 않는다 — 브랜치에서 작업한다.
- 1MB 넘는 파일을 스테이징하기 전에 먼저 말한다.
- **실행자 주의: SQLite 는 `varchar` 길이를 강제하지 않는다.** 운영 PostgreSQL 에서 500 이 나는 입력이 테스트 DB 에서는 조용히 저장된다. 그래서 길이 검사 테스트의 RED 는 `500 != 422` 가 아니라 **`201 != 422`** 로 실패한다. 정상이다.

```python
    def test_metadata_가_JSON_객체가_아니면_422(self):
```

```python
# (receive_capture 인자명, 계약 필드명, 상한). 상한은 domain/models/vision.py 의
# 컬럼 길이와 **같아야 한다**. 넘으면 PostgreSQL 이 DataError 를 내는데 그것은
# IntegrityError 가 아니어서 Service·View 의 except 를 모두 지나 500
# retryable=true 로 나가고, Client 는 같은 결과가 날 요청을 재시도 한도까지
# 다시 보낸다(요청서 R16).
METADATA_LIMITS = (
    ('request_id', 'request_id', 36),
    ('client_version', 'client_version', 50),
    ('camera_vendor', 'camera.vendor', 100),
    ('camera_serial', 'camera.serial_number', 100),
)


class MetadataError(Exception):
    """metadata 가 계약을 벗어났다. 전부 422 `METADATA_INVALID` 다.

    메시지는 **우리가 쓴 문장**이다. 파이썬 예외 원문을 그대로 넣지 않는다 —
    내부 구현이 Client 로 나간다.
    """


def parse_metadata(raw):
    """`metadata` 문자열 → `receive_capture` 에 그대로 넘길 dict.

    검증은 **이미지 파일을 쓰기 전에** 끝난다. 뒤로 미루면 거절된 요청이
    저장소에 파일만 남긴다 — 파일 쓰기는 트랜잭션 롤백 대상이 아니다.
    """
    if not raw:
        raise MetadataError('metadata 가 없다.')
    try:
        metadata = json.loads(raw)
    except json.JSONDecodeError:
        raise MetadataError('metadata 형식이 올바르지 않다.')
    if not isinstance(metadata, dict):
        raise MetadataError('metadata 는 JSON 객체여야 한다.')

    camera = metadata.get('camera') or {}
    if not isinstance(camera, dict):
        raise MetadataError('camera 는 JSON 객체여야 한다.')

    request_id = str(metadata.get('request_id') or '')
    item_id = metadata.get('inspection_item_id')
    if not request_id or item_id is None:
        raise MetadataError('request_id 와 inspection_item_id 가 필요하다.')
    try:
        item_id = int(item_id)
    except (TypeError, ValueError):
        raise MetadataError('inspection_item_id 는 정수여야 한다.')

    try:
        capture_timestamp = parse_utc(metadata.get('capture_timestamp'))
    except (TypeError, ValueError):
        raise MetadataError('capture_timestamp 는 ISO 8601 시각이어야 한다.')

    fields = {
        'request_id': request_id,
        'inspection_item_id': item_id,
        'capture_timestamp': capture_timestamp,
        'client_version': metadata.get('client_version') or None,
        'camera_vendor': camera.get('vendor') or None,
        'camera_serial': camera.get('serial_number') or None,
    }
    for key, label, limit in METADATA_LIMITS:
        value = fields[key]
        if value is not None and len(str(value)) > limit:
            # 자르지 않는다. request_id 를 자르면 Client 가 보낸 id 로
            # 재조회할 수 없는 기록이 생긴다.
            raise MetadataError(f'{label} 은 {limit}자 이하여야 한다.')
    return fields
```

```python
    def post(self, request):
        try:
            fields = parse_metadata(request.POST.get('metadata'))
        except MetadataError as exc:
            return error('METADATA_INVALID', str(exc), 422)

        upload = request.FILES.get('image')
        if upload is None:
            return error('IMAGE_REQUIRED', '이미지가 없다.', 422)
        if upload.size > MAX_IMAGE_BYTES:
            return error('IMAGE_TOO_LARGE', '이미지가 너무 크다.', 413)

        try:
            inspection, created = InspectionService().receive_capture(
                client=request.vision_client, image_bytes=upload.read(), **fields)
        except InspectionItemNotFound as exc:
            return error('INSPECTION_ITEM_NOT_FOUND', str(exc), 404)
        except RequestIdConflict as exc:
            return error('REQUEST_ID_CONFLICT', str(exc), 409)
        except ValueError as exc:
            # 여기 남는 ValueError 는 이미지 판정(_detect_format)과 저장 거절뿐이다.
            # metadata 쪽 ValueError 는 parse_metadata 가 위에서 다 걷어 갔다.
            return error('IMAGE_INVALID', str(exc), 422)

        return data(serialize_inspection(inspection), status=201 if created else 200)
```

```python
BBOX_KEYS = ('x1', 'y1', 'x2', 'y2')


@dataclass
class Defect:
    """탐지 1건. Client `_parse_defect` 계약과 필드명이 같아야 한다.

    `bbox` 는 `{x1, y1, x2, y2}` 정수다 — **원본 이미지 Pixel 좌표**이고
    `0 <= x1 < x2`, `0 <= y1 < y2` 다(요청서 R11). 이전에는
    `[x, y, width, height]` 로 적혀 있었는데 Client 가 읽는 형식이 아니다.
    구현체가 없는 동안 맞춰 둔다.
    """

    class_name: str
    confidence: float
    bbox: dict

    def __post_init__(self):
        # GPU Server 응답이 그대로 Client 로 나가는 경계다. 모양이 틀리면
        # 여기서 멈춘다 — 틀린 좌표가 나가면 작업자가 엉뚱한 위치를 본다.
        missing = [key for key in BBOX_KEYS if key not in self.bbox]
        if missing:
            raise ValueError(f'bbox 에 {", ".join(missing)} 가 없다.')
```
