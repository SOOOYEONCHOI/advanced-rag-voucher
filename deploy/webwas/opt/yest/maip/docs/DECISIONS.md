# 결정 기록

지금 유효한 결정만 모았다. 뒤집힌 결정은 최종 형태로만 적고, 폐기된 ID 는 맨 끝
[폐기·대체된 ID](#10-폐기대체된-id) 에서 무엇으로 바뀌었는지 찾는다.

ID 체계:

| 접두어 | 뜻 |
| --- | --- |
| `DEC-001`~`DEC-035` | 통합 설계 결정 |
| `O-1`~`O-16` | 위 결정을 덮어쓴 조정. 같은 주제면 O 가 이긴다 |
| `Q1`~`Q9` | 비전검사항목 단일화(O-8·O-9) 때 확정한 세부 질의 |
| `DEC-C1`~`DEC-C16` | 비전검사 클라이언트 요청서(R1~R20) 대응 |
| `F-3`~`F-8` | 의도적으로 미룬 향후 확장 |
| 사용자 결정(날짜) | ID 없이 코드 주석에 날짜로 남은 결정 |

각 절 안에서는 `DEC-0xx` → `DEC-Cx` → `O-x` → `Qx` → 사용자 결정(날짜순) 순서로 둔다.
