`.env`, `compose.env`는 묶음 안의 견본(`config/*.example`) 대신 **이 파일을 그대로 올려** 쓴다.

```bash
# 서버(yest-web, sychoi) — WinSCP 로 /mnt/a/chatbot/offline/ 에 .env·compose.env 를 올린 뒤
install -m 640 -g chatbot /mnt/a/chatbot/offline/.env /opt/yest/chatbot/.env    # 바꾸는 순서: 수정배포 가이드 4.8
install -m 640 /mnt/a/chatbot/offline/compose.env /opt/yest/chatbot/compose.env
rm /mnt/a/chatbot/offline/.env /mnt/a/chatbot/offline/compose.env
sed -i 's/\r$//' /opt/yest/chatbot/.env /opt/yest/chatbot/compose.env      # Windows 줄바꿈이 섞였을 때
ls -l /opt/yest/chatbot                                                     # sychoi:chatbot -rw-r-----
```

## 4. 확인한 것

- 운영 `.env`를 런타임 이미지 `chatbot-backend-runtime:cb63162cffc3`로 불러 봤다(네트워크 없음). `config ok`가 나왔고 모델 이름, 차원 2560, 경로, CORS가 의도한 값으로 읽혔다.
- 값 뒤에 붙인 주석이 없다. compose `env_file`은 줄 끝 `# ...`를 값의 일부로 읽는다. 개발 `.env`의 `VLLM_MAX_MODEL_LEN=24576   # 8192` 같은 줄을 옮기면 기동이 실패한다.
- 키에 `$`와 `#`가 없다(compose 보간·주석 문제).
